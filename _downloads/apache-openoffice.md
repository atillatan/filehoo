Apache OpenOffice is the continuation of the original OpenOffice.org suite. It keeps the classic interface and light system requirements, which makes it a favorite on older PCs, though LibreOffice receives updates far more frequently.

Key features:

* Writer, Calc, Impress, Draw, Base and Math
* Reads Microsoft Office formats; saves ODF standards
* Familiar classic toolbar interface
* Runs comfortably on older hardware
* Extensions and templates gallery
* Free and open source (Apache License)
