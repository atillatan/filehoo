Media Player Classic - Home Cinema is the player you install when you want videos to just open, instantly, in a window that looks like Windows and uses almost no memory. The actively maintained clsid2 fork bundles up-to-date codecs, so virtually every file plays out of the box.

Key features:

* Instant startup, tiny memory footprint
* Plays practically everything via bundled LAV Filters
* Modern dark theme, high-DPI support
* Built-in subtitle search and download
* No ads, no telemetry, fully open source
* Portable-friendly: works from a folder without installing
