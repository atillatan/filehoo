Microsoft PowerToys is a free, open-source set of utilities that supercharge Windows. Snap windows into custom layouts, batch-rename files, preview anything with a spacebar, resize images from Explorer, and launch everything from a command palette.

Key features:

* FancyZones window layout manager
* Command Palette quick launcher
* PowerRename batch renamer with regex
* Peek file previewer and Image Resizer
* Keyboard Manager, Color Picker, Text Extractor (OCR)
* Always On Top, Awake, Mouse utilities and more
