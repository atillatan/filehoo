Notepad++ is the free source code and text editor that replaces Windows Notepad with something vastly more capable, while staying tiny and instant to start.

Key features:

* Syntax highlighting and folding for 80+ languages
* Multi-tab, multi-view, split-screen editing
* Powerful search and replace with regex, across files
* Column mode, macros and auto-completion
* Plugin ecosystem (compare, JSON tools, FTP and more)
* Tiny, fast, open source (GPL)
