FileZilla is the long-standing standard for free file transfer. Connect to any FTP, FTPS or SFTP server, manage credentials in the site manager, and move files with drag-and-drop, resume and speed limits.

Key features:

* FTP, FTP over TLS (FTPS) and SFTP
* Site manager with per-site settings
* Resume support for large transfers, > 4 GB safe
* Directory comparison and synchronized browsing
* Transfer queue with speed limits
* Cross-platform and open source
