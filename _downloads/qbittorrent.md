qBittorrent is the BitTorrent client most people should use: open source, no ads, no bundled junk, with a clean Qt interface and every power feature you expect.

Key features:

* Clean interface, no ads or toolbars, ever
* Built-in torrent search engine
* Sequential downloading (watch while you download)
* RSS auto-downloading with filters
* Remote control via web UI
* Bandwidth scheduler, encryption, IP filtering
