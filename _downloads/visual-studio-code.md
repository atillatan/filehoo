Visual Studio Code is a lightweight but powerful source-code editor from Microsoft. It supports practically every language through extensions, and ships with IntelliSense code completion, an integrated terminal, a debugger and first-class Git support.

Key features:

* IntelliSense smart completions for dozens of languages
* Built-in debugger, terminal and Git integration
* 60,000+ extensions in the marketplace
* Remote development over SSH, WSL and containers
* Fast, keyboard-friendly, fully themeable
* Free for private and commercial use
