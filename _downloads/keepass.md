KeePass keeps every password you own in one encrypted database, locked with a single master key. Your data stays local, in your control, protected by AES-256/ChaCha20; no cloud account required.

Key features:

* AES-256 / ChaCha20 encrypted local database
* One master password (optionally + key file)
* Strong password generator with rules
* Auto-type into any application or browser
* Portable version runs from a USB stick
* Hundreds of plugins; open source (GPL)
