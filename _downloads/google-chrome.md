Google Chrome is a fast, secure web browser built on the open-source Chromium project. It combines a minimal interface with a powerful rendering engine, automatic updates, built-in phishing and malware protection, and sync of bookmarks, passwords and tabs across all your devices.

Key features:

* Fast page loading with the V8 JavaScript engine
* Built-in Safe Browsing protection against phishing and malware
* Sync bookmarks, history, passwords and open tabs across devices
* Huge extension ecosystem via the Chrome Web Store
* Automatic silent updates keep you on the latest version
* Built-in translation, PDF viewer and casting support
