WinSCP is the go-to Windows client for secure file transfer over SFTP, SCP, FTPS and WebDAV. Use the Norton-Commander-style dual pane or Explorer mode, automate with scripting and .NET assembly, and edit remote files in place.

Key features:

* SFTP, SCP, FTP(S), WebDAV and S3 protocols
* Dual-pane or Explorer-style interface
* Integrated text editor for remote files
* Directory synchronization and background transfers
* Powerful scripting / .NET automation
* Stores sites with encryption; open source
