Short answer: install **VLC** if you want one player that handles everything with
zero setup. Install **MPC-HC** if you want the lightest, fastest player that
feels like a native part of Windows. Both are free, open source and safe.

## The two that matter

{% include guide-app.html url="/downloads/vlc-media-player/" badge="Best overall" pitch="VLC plays literally everything - video, audio, DVDs, streams, broken half-downloaded files - with no codec packs and no configuration. It is the default answer for a reason." %}

VLC's superpower is that it never asks you for anything. Subtitles, weird codecs,
disc images, network streams: it just plays them. It can also convert files and
record your desktop in a pinch. The interface is dated, but you will rarely see
it anyway.

{% include guide-app.html url="/downloads/mpc-hc/" badge="Lightest" pitch="MPC-HC starts instantly, sips memory and looks like a native Windows app. The actively maintained fork bundles modern codecs, so it plays everything VLC does while feeling twice as fast." %}

MPC-HC was abandoned in 2017 and famously resurrected by the community. The
current fork is excellent: dark mode, high-DPI support and built-in subtitle
search. On old or low-power laptops the difference in responsiveness over VLC
is noticeable.

## Worth a mention

- **mpv**: the enthusiast's choice, keyboard-driven, no real interface. Wonderful
  if you live in config files; frustrating if you do not.
- **PotPlayer**: feature-packed but closed source, with a history of bundled ads
  in its installer. We do not recommend it while the two players above exist.
- **Windows Media Player (new)**: fine for the occasional MP4, still stumbles on
  subtitles and unusual formats.

## Head to head

| | VLC | MPC-HC |
|---|---|---|

| Memory use | Moderate | Very low |
| Extras | Convert, stream, record | Subtitle search |

## FAQ

**Is VLC really free? No catch?**
None. It is developed by the VideoLAN non-profit and funded by donations. No
ads, no bundled software, no premium version.

**Do I still need codec packs like K-Lite?**
No. Both players ship with everything built in. Codec packs are a relic of 2008
and a common source of junkware.
